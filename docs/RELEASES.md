# 发布说明

给下载页和更新提示用：每一版用户能感觉到什么变化。工程细节放在 `CHANGELOG.md`，某处为什么这么做放在 `docs/HANDOFF.md`。

## 装哪个

| 形式 | 文件 | 说明 |
| --- | --- | --- |
| 免安装 | `cuter-<版本>-portable-x64.zip` | 解压即用。配置、日志、截图历史、默认保存目录都在 exe 旁边，不碰系统 |
| 安装 | `cuter-<版本>-x64-setup.exe` | 装进 `%LOCALAPPDATA%\Programs\Cuter`，不需要管理员。卸载时保留你的配置 |

默认热键（设置里都能改）：

| 热键 | 作用 |
| --- | --- |
| `Alt+C` | 框选截图 |
| `Alt+X` | 截当前显示器 |
| `Alt+S` | 滚动截屏（框选后回车开始；按 `A` 让程序替你滚） |
| `Alt+V` | 把剪贴板里的图贴到屏幕上 |
| `Alt+H` / `Alt+G` | 隐藏/显示本组贴图、切到下一组 |
| `Alt+O` | 识别屏幕上的文字 |

## 最近几个版本

### 0.1.70 手动滚动截屏补上验证

滚动截屏有两种用法：程序自己滚，和人来滚、程序只负责拼。第二种是实际最常用的，但之前只有前一种有自动化探针。这一版补了 `scroll_manual_e2e.ps1`：把配置改成手动模式，探针自己滚十四轮，再读应用日志确认帧数和拼出来的高度。实跑 23 帧，750×550 的选区拼成 750×3493。功能本身没改，改的是"我能证明它能用"。

### 0.1.69 更新检查不再每次启动都联网

- 启动时检查更新，一天最多一次；手点「立即检查」不受限制。
- 不想升某个版本，在「设置 → 关于」点「跳过这个版本」，以后不再提它，随时可以取消。
- 开机那几秒网络还没起来导致的失败，会自动重试一次。

### 0.1.68 日志里每句话写两遍的根因

双击启动时程序会丢掉 Windows 附赠的控制台，但那三个标准句柄的数值还留在进程环境块里。紧接着打开日志文件，系统把这个数值又分配给了日志文件，于是"写 stderr"实际写进了日志文件，控制台和文件两份叠在一起。现在丢控制台之后顺手把槽清空，连续启动六次重复 0 处（修之前约一半的启动会重复）。

### 0.1.67 贴图边上那圈灰边

贴图窗口四周原来留 12 像素画投影，浅色桌面上看着像一圈灰边框；图片圆角大的时候四角还会露出方角。现在留白收到 7 像素、九层更淡的叠加、整体下移 1.5 像素，每层圆角跟着图片走。拖边缘缩放不受影响。

### 0.1.66 中文方框字

窗口全关两秒会卸载字体，下次开窗口再装，而装字体要下一帧才生效，于是那一帧里所有中文都是方框。现在字体装一次就不再卸，多占 22 MB 私有内存，换掉整片方框。

### 0.1.65 待命时"点了没反应"

0.1.62 为了省电把待命时的重绘间隔拉长到最多 4 秒，代价是所有"等下一帧"的动作都变慢：托盘菜单要三秒多才消失、命令行转发要等下一次轮询、探针偶尔超时。这一版让这三条路径自己叫醒主循环，不再排在上限 4 秒的队里。

## 更早的版本

0.1.13 到 0.1.64 的逐条改动见 `CHANGELOG.md`。0.1.13 之前是开发期，没有对外发布说明。

## 已知限制

没有代码签名。Windows SmartScreen 会提示"未知发布者"，Defender 也误报过一次（`Behavior:Win32/Persistence.A!ml` 并拦截执行）。原因是它确实会写开机自启项、常驻全局热键，而无签名程序做这些事没有信任来源。签名证书能根治，暂时只能在提示里选"仍要运行"，或把 exe 加进 Defender 排除项。

只在单显示器上验证过，开发机只有一块屏，多显示器混合缩放没有真机验证。

取字用的是 Windows 自带的 OCR。中文需要系统装了中文语言包，竖排和旋转的文字目前只按轴对齐矩形返回，准确率一般。

自动滚动对部分程序无效，它们忽略合成的滚轮消息，遇到这种请手动滚。

在线能力需要你自己提供 HTTP 端点，程序里没有内置服务。目前能接的是 PaddleOCR 的 hubserving 接口，本地怎么起服务写在 `docs/HANDOFF.md` 第 73 节。

## 配置在哪

便携版全部在 exe 旁边：`config.toml`、`logs\`、`data\history\`、`Screenshots\`。

安装版在 `%APPDATA%\Cuter\`（配置和日志）与 `%LOCALAPPDATA%\Cuter\history\`（截图历史）。

设置 → 诊断里有「打开日志目录」，出问题时把 `logs\cuter.log` 发出来能定位大半。
