| 界面 | 节点 id | 位置 |

| 遮罩与工具条 / 框选状态 | `13:320` | (2500, 120) |

一块 1280×900 的板子里放了四件事：选区（840×560、accent 描边、8 个控制点、三分线、"840 × 560" + 坐标标签）、选区外的压暗（45%）、工具条 `13:358`、工具选项弹窗 `13:394`、放大镜 `13:409`。

## 这套 Figma 接口的实测坑（踩过才知道）

- MCP 工具名带前缀：`mcp__figma__use_figma` / `mcp__figma__whoami` / `mcp__figma__create_new_file` / `mcp__figma__get_screenshot`；裸名 `use_figma`、`whoami`、`get_figma_skill` **都不存在**。
- `use_figma` 必填 `description`，否则报 `Invalid arguments … expected string, received undefined`。
- `skillNames` 必须带 `resource:` 前缀（`resource:figma-use,resource:figma-generate-design`）。
- **插件脚本抛异常时，本次调用的全部改动会被回滚**（连已 appendChild 的节点也会消失）——所以脚本要一次做完一件事，别指望"失败前半成品"。
- **文字样式不能用**：`figma.createTextStyle()` 后的属性赋值会抛 `TypeError: object is not extensible`（与把变量绑定到 paint 有关），本接口下不可用；字号/行高改为逐文本设置，效果等价。**阴影样式可以正常创建。**
- 普通对象上不要用 `||=`（`(obj[k] ||= []).push(x)`）——同样会撞上 `object is not extensible`，写显式 `if`。
- 按**名字** `findAll` 找组件不可靠（实际失败过一次）；按 id `getNodeByIdAsync` 取才稳。变体集里取变体用 `set.children.find(ch => ch.name.indexOf("选中") >= 0)`。
- 变量值可以带 alpha（`{r,g,b,a}`），paint 的颜色不行；`setBoundVariableForPaint(paint, "color", variable)` 能把填充绑到变量。
- **`ELLIPSE` 没有 `clipsContent`**（`TypeError: no such property 'clipsContent' on ELLIPSE node`）：要裁剪的圆形（放大镜）得用 frame + `cornerRadius = 边长/2` + `clipsContent = true`。
- 变量的 `scopes` 没有 `EFFECT` 这个名字，模糊半径要用 **`EFFECT_FLOAT`**（有效值是 `ALL_SCOPES`/`ALL_FILLS`/`FRAME_FILL`/`SHAPE_FILL`/`TEXT_FILL`/`STROKE_COLOR`/`EFFECT_FLOAT`/`EFFECT_COLOR`/`WIDTH_HEIGHT`/`GAP`/`CORNER_RADIUS`/`OPACITY`/`COLOR_OPACITY`/字体那一组）。
- 脚本里的中文字符串**不能用半角双引号嵌套**（`"…多一层"被框住"含义…"` 直接语法错、整批回滚），用 `「」` 或全角引号。
- 半透明填充直接写 `{ type: "SOLID", color: {r,g,b}, opacity: 0.45 }` 最省事（变量绑定只绑颜色，alpha 留在 paint 上）。
- 出稿后**必须逐张看图**：三轮共抓到 6 个真排版 bug（第五行被下一张卡片压掉、工具条底板宽度算少导致按钮画到框外、警告行叠字、kv 行被 52px 行高压掉、尺寸标签写的数字与实际选框不符、放大镜像素网格溢出圆外）。脚本不报错不等于版面对。
