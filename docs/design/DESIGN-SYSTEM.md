# Cuter 设计系统 v1（草案，等你确认）

配 4 张高保真稿：`docs/design/mockups/{tokens,settings,ocr-panel,overlay-toolbar}.svg` / `.png`。
气质：**现代深色工具风**（克制、单一强调色、信息分层）。

## 0. 这套东西怎么用

* **导入 Figma**：Figma 原生支持导入 **SVG**。把 `mockups/*.svg` 直接拖进画布，就是可编辑的矢量图层
  （形状、文字、颜色都能改）。它不是 `.fig` 文件，也没有组件/auto-layout 语义——这点我不含糊。
* **可复现**：所有稿子由 `tools/design/make_mockups.py` 生成（一份几何 → SVG + PNG 两个渲染器），
  改个令牌重跑一次就全量更新，不会出现"稿子和实际不一致"。
* **尺寸是 1:1 的**：设置窗口 980×660、OCR 面板 980×620，正是程序里视口的客户区大小
  （外面还有系统标题栏）。工具条高 48、按钮 34、圆角 12，也是 1:1。
* **PNG 是我自己看的预览**（Pillow 渲染），保证"我看到的和你看到的是同一张图"。

## 1. 四条设计原则

1. **一个强调色**。界面上只有 `accent` 一种彩色（蓝），红/黄/绿只用于语义（危险/警告/成功），
   绝不用于装饰。截图工具的界面永远不该抢截图的注意力。
2. **层次靠字号与颜色，不靠字重**。egui 里我们只加载一份字体（msyh.ttc 单字重），
   所以标题与正文的区别是 20px/13px + `text/primary`/`text/secondary`，不是 bold。
   这条是**实现约束倒推的设计决定**，不是妥协：结果反而更干净。
3. **4px 网格**。所有间距、尺寸、圆角都取 4 的倍数（4/8/12/16/24/32）。
4. **一屏一个主操作**。设置窗口的头部只有一个实心按钮「开始截图」，其余操作进「⋯」；
   工具条上只有一个实心按钮「完成」。实心 = 唯一强调，其余都是描边或纯色块。

| 名称 | 字号 | 行高 | 颜色 | 用在哪 |
|---|---|---|---|---|
| `title-1` | 24 | 32 | primary | 面积/大标题（几乎不用） |
| `title-2` | 20 | 28 | primary | 页面标题（"通用"） |
| `title-3` | 15 | 22 | primary | 卡片标题、面板标题（"外观与启动"） |

| `caption` | 11 | 16 | tertiary | 说明文字、胶囊、页脚、元信息 |

## 4. 间距 / 圆角 / 阴影

**间距**：`4 · 8 · 12 · 16 · 24 · 32`（4px 网格）。
常用组合：卡片内边距 16；行与行 12；卡片之间 16；页面内容左右 24；侧栏项之间 4。

**圆角**：输入框/复选框 `6` · 按钮 `8` · 卡片 `10` · 窗口与弹层 `12`（浮动工具条）~ `14`（大弹窗）。

**阴影**：只有浮层有阴影——`0 8 24 rgba(0,0,0,.45)`；卡片不用阴影，用 `border/subtle` 分开。
（egui 里用 `epaint::Shadow` 近似；实在不行用 1px 亮边模拟。）

| 控件 | 规格 |

| 次级按钮 | 高 32，`bg/raised` 底 + `border/strong` 1px 边 + primary 字 |
| 图标按钮 | 34×34（工具条）/ 32×32（弹窗），圆角 8，图标 18px |
| 复选框 | 18×18，圆角 6；未选中 `bg/sunken` + `border/strong`；选中 `accent` 底 + 白勾 |
| 下拉框 | 高 30-32，圆角 6，`bg/sunken` 底；右侧 16px chevron，`text/secondary` |
| 分段控件 | 高 30，外框 `bg/sunken` + 圆角 8，选中段 `accent/subtle` + `accent` 字 |
| 卡片 | `bg/raised` + 1px `border/subtle` + 圆角 10 + 内边距 16；标题 15px 在卡片内顶部 |
| 列表行 | 高 40，圆角 8；hover/选中 `accent/subtle`；行内右侧 hover 才出现的图标按钮 |
| 胶囊（元信息） | 高 19（11px 字 + 上下 4），圆角 6，`bg/raised` 底，`text/secondary` 字 |
| 分隔线 | 1px `border/subtle`；竖分隔在工具条里高 20、上下留 14 |
| 焦点态 | 2px `accent` 描边（键盘导航用，鼠标点击不显示） |
| 禁用态 | 文字 `text/tertiary`，无 hover 反馈 |

## 6. 图标

16×16 网格绘制、**1.6px 描边**、圆头圆角、颜色取 `currentColor`（随状态变）。
界面里出现三档：16（侧栏、行内）、18（工具条）、20（空状态）。
现有工具条图标已经全部矢量绘制，保留，只按新色与描边规范统一。

**设置窗口（980×660）**

```
┌────────────┬──────────────────────────────────────────────┐
│ 220 侧栏    │ 头部 96：页面标题 20 / 一句说明 12 / 主操作     │
│ bg/sunken  ├──────────────────────────────────────────────┤
│ 分组标题 11 │ 内容区 padding 24，卡片之间 16                │
│ 项高 32     │ 卡片：标题 15 + 行（标签 13 + 说明 11 + 控件）  │
│ 项间距 4    │ 行高 52，行间 1px 分隔线                       │

```

**OCR 面板 / 滚动面板 / 历史面板**（同一套外壳）：头部 52（标题 + 元信息胶囊 + 分段控件）·

**浮动工具条**：高 48、圆角 12、`bg/overlay` + `border/subtle`、内边距 12；
分组用竖分隔线；选区尺寸胶囊浮在工具条上方 8px。

## 10. 已知限制（先说清楚，免得实现时扯皮）

* **没有字重**：msyh.ttc 单字重，所以"加粗"只能用字号/颜色表达（见原则 2）。
* **没有真实模糊/亚克力**：egui 不做 backdrop blur，浮层是"实色 + 边框 + 阴影"。
* **圆角靠 `rect_filled(rounded)`**，图片本身要圆角得在 CPU 上裁（贴图已经这么做了）。
* **动画**：hover 120ms、面板出现 180ms（`animate_bool_with_time`）；不做弹簧/位移。
* **Figma 稿是静态图层**：导进去能改颜色和文字，但没有组件、变体、auto-layout——需要的话我按 Figma 的
  命名约定再出一版分层更细的 SVG（每个控件一个 `<g>` 带 `id`）。
* **浅色主题**：令牌表里只给了深色一套。你说要跟随系统的话，浅色我需要再出一版对照
  （`bg/base #FFFFFF`、`bg/raised #F6F7F9`、`text/primary #1B1D22`、`border/subtle #E4E6EB`、
  accent 不变——这套值是我按同一套规则推的，还没出稿）。
